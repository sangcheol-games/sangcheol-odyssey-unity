# 오디오·타이밍 레이어 재설계 자료

FMOD 오디오 레이어 재설계(브랜치 `refactor-FMOD`)의 조사, 결정, 설계 원본을 보관하는 폴더다. Unity 프로젝트 밖(`Assets` 바깥)에 있으므로 임포트되지 않고 빌드에도 영향이 없다.

## 먼저 읽을 문서(구현 기준)

| 문서 | 내용 |
|---|---|
| `Assets/Scripts/Audio/Audio_architecture.md` | 구조: 계층, 계약, 수명주기, 곡 시계, 판정 타이밍, 스레드 규칙 |
| `Assets/Scripts/Audio/Audio_migration.md` | 이행: **0장 인수인계**, 단계 카드, 스파이크, 통합 지점, 스파이크 결과 |

두 문서가 이 폴더의 자료보다 우선한다.

## 이 폴더의 자료(근거와 이력)

| 파일 | 내용 | 언제 보나 |
|---|---|---|
| `01_fmod-usage-audit.md` | 기존 FMOD 사용 방식과 검증된 문제점(H/M/L 이슈) | 왜 바꾸는지, 기존 코드가 어떻게 동작했는지 확인할 때 |
| `02_decision-brief.md` | FMOD·Unity 동작의 검증된 사실(F1~F37)과 출처, 소유 방식 비교, 스파이크 근거 | 구현 중 FMOD 동작이나 결정 근거를 확인할 때 |
| `03_design-rev2.md` | 설계 원본(개정 2). 폐기된 내용 포함 | 구조 문서의 세부 배경이 필요할 때(참고용) |
| `04_plan.md` | 승인된 계획 전문 | 결정 과정과 검수 이력을 볼 때 |

이 폴더는 재설계 이행이 끝나는 C 단계에서 유지할지 삭제할지 정한다.
