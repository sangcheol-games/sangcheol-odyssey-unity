# ChartPorter

노멀 채보를 하드 초안으로 포팅하는 도구다. 기준은 채보 리드가 직접 찍은 2번 곡의 노멀→하드 기조이고, 음원(librosa)으로 "실제로 소리가 있는 칸"에만 노트를 더한다.
결과는 **초안**이다. 최종 판단은 ChartEditor와 실제 플레이로 한다.

계획 전체: 진행 단계 M0–M9 (아래 '진행 상황')

## 설치

Windows PowerShell에서 실행한다.

```powershell
cd Tools/ChartPorter
powershell -ExecutionPolicy Bypass -File setup_env.ps1
```

- `.venv/`를 만들고 `requirements.lock.txt` 버전 그대로 설치한다(librosa, numpy, scipy, soundfile, pyyaml, pytest).
- 이 폴더는 `Assets/` 밖이라 Unity가 가져가지 않는다.

## 사용법

```powershell
.\.venv\Scripts\python.exe -m chartporter check          # 모든 곡 검사
.\.venv\Scripts\python.exe -m chartporter check 4 6      # 곡 번호로
.\.venv\Scripts\python.exe -m chartporter check ..\..\Assets\Charts\Chart_0004_Normal.txt -v
.\.venv\Scripts\python.exe -m pytest -q                  # 테스트
```

Windows PowerShell 5.1에서 결과를 변수·파이프·파일(`> log.txt`)로 받으면 일본어·한국어가 깨진다. 콘솔이 cp949라서 생기는 문제다. 받기 전에 아래를 한 번 실행한다(화면에 바로 출력할 때는 필요 없다).

```powershell
[Console]::OutputEncoding = [Text.Encoding]::UTF8
```

```powershell
.\.venv\Scripts\python.exe -m chartporter fmt 6                     # 수정안 diff 출력 + out/0006/fmt/ 에 저장
.\.venv\Scripts\python.exe -m chartporter fmt 6 --orphan-end tap --apply   # 백업(out/0006/backups/) 후 적용
```

`fmt`가 자동으로 고치는 것: 빠진 마디(빈 줄로 채움), `#DIFFICULTY`(파일 이름에 맞춤), `#NOTES`(다시 셈). 내용이 바뀌는 수정은 옵션으로 고른다.

- **짝 없는 `4`**: `--orphan-end keep|tap|drop`
- **끝 없는 홀드·마디를 넘는 홀드**: `--close-holds`. 7/8에 `4`를 붙이고, 7/8 이후 시작은 탭으로 바꾼다. 7/8과 시작 사이에 같은 레인 노트가 있으면 직접 확인하도록 남긴다.
- **`port`**: 끝 없는 홀드를 남기지 않는다. 손작업·복사·노멀 유지 마디도 마지막에 같은 규칙으로 닫는다. `--apply`는 수정안을 만든 뒤 파일이 바뀌었으면(에디터 저장 등) 적용하지 않는다. 적용 후 FATAL/ERROR가 늘면 원래 파일로 되돌린다.

### 하드 기조 통계

```powershell
.\.venv\Scripts\python.exe -m chartporter stats 2 3 --primary 2    # 기준 곡 노멀/하드 비교 → profiles/style_profile.json
```

- 노멀의 각 노트가 하드에서 어떻게 됐는지 분류한다: 유지, 같은 그룹 위아래 교체, 다른 그룹으로 이동, 1/16 이동, 삭제.
- 하드에만 있는 노트가 어디에 들어갔는지 분류한다: 빈 칸 채우기, 앞뒤로 늘림, 노멀과 같은 시각.
- 마디마다 기믹(두 그룹 사용과 그 방향, 메인 그룹 반전·제거)과 홀드 변화를 센다.
- 16분 홀수 칸 하드 노트(청취 확인 대상)와 1·2절 복사본 마디(`sections`의 `copy_of`)는 학습에서 뺀다.

### 하드 초안 만들기와 평가

```powershell
.\.venv\Scripts\python.exe -m chartporter port 4                    # → out/0004/port/Chart_0004_Hard.txt, report.md, port_log.json
.\.venv\Scripts\python.exe -m chartporter install 4                 # 초안을 Assets/Charts 에 설치 (기존 파일 백업, 지난 설치 뒤 직접 고친 파일은 --force 없이는 안 덮어씀)
.\.venv\Scripts\python.exe -m chartporter install 1 --diff Easy      # 이지·노멀 초안(out/000N/gen/) 설치. 상태는 난이도별로 out/000N/install_state.json
.\.venv\Scripts\python.exe -m chartporter eval 2 3                  # 기준 곡 노멀을 포팅해 사용자 하드와 비교
.\.venv\Scripts\python.exe -m chartporter eval 2 --oracle-budget    # 마디별 추가 수를 사용자와 같게 주고 '어디에 넣는지'만 평가
.\.venv\Scripts\python.exe -m chartporter uturns 2                 # 유턴 앞쪽 노트 목록 → out/0002/uturns_Chart_0002_Hard.md (직접 찍은 채보 확인용)
```

- **port**는 `profiles/style_profile.json`(2번 기조)을 따라 노멀에서 하드 초안을 만든다. 초안은 `out/`에만 쓰고 `Assets/Charts`는 건드리지 않는다. 노멀에 끝 없는 홀드(E13/E14)가 남아 있어도 진행한다(하드 쪽에서 닫음).
  1. **홀드**: 끝 없는 홀드는 시작이 7/8 미만이고 사이에 노트가 없으면 7/8에 `4`를 붙이고, 7/8 이상이면 탭으로 바꾼다. 다음 마디로 넘어가던 끝은 지운다. 그 밖은 리포트에 '직접 확인'으로 표시한다.
  2. **추가 예산**: 노멀 분할별 배율(4분할 ×1.39, 8분할 ×1.05)에 `density_scale`을 곱해 정한다. 음원 밀도가 노멀보다 큰 마디에 더 많이 배분한다(마디당 최대 3).
  3. **기믹** (`gimmicks.py`, 2번·3번 사용자 하드를 반반으로 섞음 — 사용자 결정): 빈 칸 소리가 큰 마디부터 약 43%를 고르고, 이웃 기믹 마디에 보너스를 줘 2–4마디씩 이어지게 한다(사람 84–88%).
     형태는 키 해시 가중 추첨이다:

     | 형태 | 모양 | 짝수 / 홀수 가중치 |
     |---|---|---|
     | 1/2 하나 (HALF1) | 1/2 다른 그룹 아래 레인 (예전 T1) | .28 / 0 |
     | 하나 (SINGLE) | 3/8·5/8·3/4·1/4 하나, 메인 노트를 옮기거나 소리 있는 빈 칸 | .17 / .18 |
     | 쌍·3연 (PAIR) | 1/2+5/8, 3/8+1/2, 1/2·5/8·3/4 | 0 / .31 |
     | 끝 문답 (RESPONSE) | 마디 끝 2–4노트를 다른 그룹으로 (4분 사이 8분 하나 채움 가능) | .09 / .25 |
     | 앞 부르기 (CALL) | 마디 앞 2–3노트 | .10 / .03 |
     | 주고받기 (INTERLEAVE) | 4분·8분 간격으로 이어진 메인 노트를 한 칸 걸러 | .27 / .17 |
     | 마디 통째 (WHOLE) | 메인 라인을 비우고 전부 다른 그룹 | .05 / 0 |
     | 메인 뒤집기 (REVERSE, 앞 부르기·주고받기의 +REV 변형) | 메인 라인 방향 뒤집기 | .05 / .07 |
     | 두 그룹 동시치기 (CHORD) | 메인 탭과 같은 시각에 다른 그룹 탭 | .04 |

     - 홀드는 시작·끝을 함께 옮긴다. 채우는 추가 노트는 소리 P30 이상(하나·1/2 하나는 P50).
     - 다양성: 이웃 기믹과 같은 형태 ×0.4, 같은 모양은 음악이 같을 때만 연속, 형태 35%·모양 20% 상한.
     - 범위는 `gimmick_level` (기본 3): 1 = 노트 넘기기만, 2 = + 메인 라인 뒤집기·통째, 3 = + 두 그룹 동시치기.
     - 계획마다 적용 → 간격·홀드·유턴 앞쪽 검사 → 실패하면 되돌림. 손작업 마디 옆은 최종 내용(`eventual_bar`)으로 검사한다. 복사로 생긴 메인 뒤집기 유턴은 마지막에 메인 방향을 되돌린다(`UTURN_UNREVERSE`).
  4. **빈 칸 채우기**: 소리가 곡 P50 이상인 빈 8분 칸만 쓴다. 레인은 직전 노트와 위아래 교대한다. 유턴 마디의 앞쪽 칸은 쓰지 않는다. 16·12분할 노멀 마디는 8분할 비율로 예산을 받는다(전에는 0).
  4b. **리듬 변주** (`rhythm.py`): 음원 16분 정점 마디(비슷한 마디 묶음 단위, 마디 18% 상한)에 약한 8분을 16분 뒤로 밀기·다음 노트 앞 16분 픽업, 셋잇단으로 들리는 박에 A-B-A 셋잇단. 레인은 번갈아 써서 같은 레인 16분은 없다. 미리듣기는 `out/000N/port/clips/rhythm_*.wav`.
  5. **유턴 앞쪽 노트 피하기**: 같은 그룹을 연달아 두 마디에 반대 방향으로 쓰면(유턴) 뒷 마디의 판정 위치 p 노트는 약 2p 마디만 보인다(고스트를 거의 거치지 않음). 앞쪽 = 0 < p ≤ 1/4 (p = 0은 끝점이라 괜찮음).
     - 뒤집는 기믹을 넣으면 다음 마디 앞쪽에 노트가 생길 때: 1개면 그 노트를 빼고 유턴 유지(`UTURN_DROP`), 2개 이상이면 그 기믹을 쓰지 않는다(다음 템플릿, 마지막은 T1o).
     - 복사·손작업 덮어쓰기 뒤 마지막 정리: 생성기가 뒤집은 기믹이 원인이면 방향을 되돌리고(`UTURN_UNFLIP`), 아니면 앞쪽 노트가 1개일 때만 뺀다. 손작업·잠금 마디가 원인이면 리포트에 `UTURN`으로 표시만 한다.
  6. **항상 지키는 것**: 동시치기 없음, 16분 엇박 없음, 같은 레인 간격 ≥ max(8분, 126ms). 복사 규칙이 있으면 반복 구간에 적용한다. 검증 경고가 나면 점수 낮은 추가 노트부터 뺀다.
- **report.md**: 먼저 볼 마디(다시 찍기 권장, 소리 약한 칸에 넣은 노트, 청취 대상)와 마디별 변경(노멀 → 초안)을 보여 준다.
- **eval** 결과 (16분 홀수 칸 제외, 무작위 기준선은 생성기와 같은 수·같은 빈칸 기준):
  - 2번 (주 기준, 2번 기조로 맞춘 결과라 다소 낙관적):

    | 지표 | 생성기 | 무작위 |
    |---|---|---|
    | 추가 노트 정밀도 | 0.55 | 0.33 |
    | 사용자와 같은 추가 수에서 정밀도 / 재현율 | 0.59 / 0.53 | 0.45 / 0.38 |
    | 기믹 마디 F1 | 0.56 (형태 일치 0.54, 유턴 규칙 전 0.61) | |
    | 7/8 홀드 끝 | 사용자 14곳 모두 일치 (생성 17) | |
    | 앞쪽 노트가 있는 유턴 | 0 (사용자 16) | |

  - 3번 (팀원 노멀 위 사용자 하드): 무작위보다 낫지 않다(0.36 vs 0.46, 같은 수 0.56 vs 0.60).
    - 사용자가 빈 칸을 거의 다 채워서 순위보다 간격·홀드 제약이 결과를 정한다.
    - 가장 큰 차이는 양이다(사용자 ×1.37).
- 곡 설정 `density_scale`(기본 1.0)로 추가 노트 양을 조절한다. 3번 사용자 하드처럼 팀원 노멀을 더 촘촘하게 하려면 1.5–3.0을 쓴다.

### 신규 곡 순서 (이지 → 노멀 → 하드, 단계마다 멈춤)

1. 음원(OGG, 1마디가 0초에서 시작하도록 만든 것)을 두고 `songs/000N.yaml` 에 `id`, `title`, `artist`, `bpm`(정수), `audio`(경로), `levels` 를 적는다.
2. `align N` → 메트로놈 클립을 듣고 `downbeat_ok: true`, `region: {last_bar: …}` 를 적는다.
3. `sections N` (채보 없이 음원만으로 반복 구간 제안: 짝수 간격 same, 홀수 간격 cross) → 맞는 규칙을 `sections` 로 옮긴다. 같은 규칙이 이지·노멀·하드에 똑같이 쓰인다.
4. `gen N` → 리포트·미리듣기 확인 → `install N --diff Easy` → ChartEditor 에서 불러와 고치고 저장.
5. `gen N --diff Normal` (고친 이지가 기반) → `install N --diff Normal` → 고치기.
6. `port N` → `install N --diff Hard` → 고치기. 반복 구간 원본을 고친 뒤에는 `sync N --diff <난이도> --apply` 로 대상 마디에 다시 복사.
7. MusicSO_000N 은 사용자가 만든다 (chartFile 슬롯·level·BPM·음원·로컬라이즈 키). 도구는 .asset 을 고치지 않는다.

`evalgen chain 2 3` (기존 곡으로 전체 연결 평가, 노트 시작 F1):

| 곡 | 시작 | 이지 | 노멀 | 하드 | 하드 마디당 (실제) |
|---|---|---|---|---|---|
| 2 (사용자) | 음원부터 | 0.76 | 0.74 | 0.71 | 5.03 (5.45) |
| | 실제 이지부터 | — | 0.87 | 0.81 | 5.30 |
| | 실제 노멀부터 (= port) | — | — | 0.87 | 5.15 |
| 3 (팀원 이지·노멀, 사용자 하드) | 음원부터 | 0.73 | 0.73 | 0.72 | 5.16 (5.55) |
| | 실제 이지부터 | — | 0.66 | 0.69 | 4.26 |
| | 실제 노멀부터 (= port) | — | — | 0.76 | 4.42 |

단계마다 0.06–0.10 씩 떨어진다 — 단계마다 사람이 고치는 이유. 3번은 팀원 이지가 성겨서(마디당 2.4) 사용자 방식 노멀도 성기다. 유턴 앞쪽 노트·오류는 모든 연결에서 0.

### 신규 곡 음원 준비 검사 (align)

```powershell
.\.venv\Scripts\python.exe -m chartporter align 7      # → out/0007/align.md, align.json, clips/align_metronome_*.wav
```

- 신규 곡은 MusicSO 가 없어도 `songs/000N.yaml` 에 `bpm`(정수)과 `audio`(음원 경로, 절대 경로 가능)를 적으면 돈다. 둘 다 있으면 BPM 이 같아야 한다.
- BPM·위상·첫 박을 **찾지 않고 검증**한다 (기본 librosa 템포 추정은 기존 6곡 중 4곡에서 박자를 잘못 잡음). 게임은 정수 BPM 이고 곡별 오프셋이 없어서 1마디가 음원 0초에서 시작해야 한다.

  | 코드 | 종류 | 기준 (기존 6곡 실측) |
  |---|---|---|
  | A01 | STOP | 8분 빗 맞춤을 B±2 에서 0.01 간격으로 훑은 정점이 B ±0.02 (6곡 ±0.01) |
  | A02 | STOP | 8분 엇박 ≥ 1.4×중앙값, 16분 엇박 ≤ 1.25× → B/2·2B 아님 (6곡 ≥1.77, ≤1.07) |
  | A08 | STOP | 1/3·2/3 박 세기 < 8분 엇박 세기 (셋잇단·셔플 곡은 8분 격자로 찍기 어려움) |
  | A03 | STOP | 4분 격자로 구한 분석 오프셋이 −45…−10 ms (6곡 −18…−32, STFT 편향 −36ms 포함). 밖이면 음원 패딩·트림 |
  | A03b | WARN | 정박 세기 < 8분 엇박 세기면 반 박 밀렸을 수 있음 (1번은 1.92 / 1.89 로 비슷해서 중지 기준으로 쓰지 않음) |
  | A04 | STOP / WARN | 8마디 창별 오프셋 기울기 > 10 ms/100마디면 중지(템포 변화), 범위 > 15 ms 면 경고 (5번 17 ms) |
  | A05 | WARN | 박 앞뒤 멜 변화가 1박에서 가장 커야 함, 여유 < 1.05 면 경고 (6곡 모두 1박, 5번 여유 1.03) |
  | A06 / A07 | INFO | 음원 길이가 마디에 맞는지, 마지막 마디 제안(RMS ≥ 중앙값 −20dB, 6곡 중 2곡 1마디 차이), 못갖춘마디 |

- **사람이 확인할 것**: 메트로놈 클립(높은 클릭 = 1박)을 듣고 `downbeat_ok: true`, 마지막 마디를 `region: {last_bar: N}` 으로 적는다. 이지 생성은 이 두 값이 있어야 진행한다.
- 분석 오프셋: `offset_ms` → (신규 곡이거나 기준 채보가 없으면) `align.json` → 기준 채보 노트 위치 추정 순서. 기존 곡은 align 을 돌려도 채보 기준 값을 계속 쓴다.

### 음원으로 이지 만들기 (gen --diff Easy, 신규 곡)


### 손작업 하드 마무리 (mode: finish)

`songs/0001.yaml`처럼 `mode: finish`를 쓰면 다음 순서로 초안을 만든다.

1. **원본 읽기**: `finish_source`의 손작업 하드를 읽는다. git 커밋(`git:<커밋>:<경로>`)도 가리킬 수 있어서, 설치 뒤 다시 실행해도 이중으로 옮겨지지 않는다.
2. **시간 이동**: 원본에 `finish_retime`(예: −1/8 마디)을 적용한다. 규칙은 사용자가 1번 노멀을 리타이밍할 때 쓴 것과 같다.
   - 앞 마디로 넘어간 노트는 다른 그룹의 같은 높이 레인으로 간다.
   - 0에서 시작하는 홀드는 그 자리에 둔다.
3. **조합**: `frozen_bars`는 그 결과를 그대로 쓰고, 나머지 마디는 지금 노멀에서 생성한다.
4. **확인 표시**: `finish_normal_source`(리타이밍 전 노멀)를 주면, 사용자가 노멀을 리타이밍할 때 직접 고친 칸이 손작업 마디에도 있는 경우를 리포트에 표시한다.

### 구간 맵과 1·2절 복사

```powershell
.\.venv\Scripts\python.exe -m chartporter sections 4        # 반복 구간 제안 → out/0004/sections.md, sections.proposed.yaml
.\.venv\Scripts\python.exe -m chartporter sync 3            # songs/0003.yaml 의 복사 규칙 미리보기
.\.venv\Scripts\python.exe -m chartporter sync 3 --apply    # 백업 후 적용
```

- **sections**: 마디마다 8분 단위로 log-mel, 크로마(화성 65–2100Hz, 멜로디 250–1500Hz), 3대역 onset을 뽑아 비교한다.
  - **같음**: dB 차 ≤ 1.
  - **반주 같음**: 종합 ≥ 0.85, dB ≤ 3.5, 멜로디 ≥ 0.85.
  - **비슷함**: 멜로디가 곡 기준선 이상.
  - 12개 조옮김을 시험하고, 8마디 이상 떨어진 반복만 본다.
  - 3번 곡의 알려진 구간 맵과 사용자가 쓴 복사 규칙을 그대로 찾아낸다(테스트).
  - 복사 규칙 후보는 '같음/반주 같음'만 낸다. 변환은 노멀 관계를 따른다(S → same, M → mirror, 그 밖 → manual).
- **sync**: `sections`의 `copy_of` 규칙을 하드에 다시 적용한다. 마디마다 아래처럼 판단한다.
  - 지난번 sync가 쓴 내용 그대로이거나, 처음 실행인데 노멀 그대로인 마디 → 새 복사본으로 바꾼다.
  - 그 밖 → 직접 고친 것으로 보고 건너뛴다. `locked_bars`에 넣거나 `--force`로 덮어쓴다.
  - 상태는 `out/000N/sync_state.json`에 둔다.

### 음원 분석·청취 확인

```powershell
.\.venv\Scripts\python.exe -m chartporter analyze 1 2 3 4 5 6     # 음원 특징 계산(cache/) + 분석 오프셋
.\.venv\Scripts\python.exe -m chartporter checklist 2             # 8분 그리드 밖 노트 확인 목록 + A/B 미리듣기

```

- **analyze**: 곡마다 librosa 특징을 한 번 계산해 `cache/`에 둔다(곡당 약 5초). 노멀 노트 위치에서 중역(150–2500Hz) 소리 시작 세기가 가장 큰 **분석 오프셋**을 찾는다.
  - 이 값은 STFT 프레이밍 편향을 포함한 분석용 보정값이다(합성 클릭으로 재면 −36ms). 게임 싱크 값이 아니며 채보에 쓰지 않는다.
  - 16마디 구간별 값이 10ms 넘게 흔들리면 경고한다.
- **checklist**: 8분 그리드 밖 노트(16분 엇박, 셋잇단)마다 다음을 적는다.
  - 가장 가까운 소리 시작까지의 거리.
  - 이 칸의 소리 크기 순위: 곡 전체의 같은 종류 칸 중 백분위. 높으면 드럼에 묻힌 약한 소리가 있을 수 있다.
  - 결과는 `out/000N/checklist_*.md/.csv`에 쓴다. 기준 곡(role: reference)은 하드, 대상 곡은 노멀이 기본이다.
- **미리듣기 클릭음**: 위 레인(1·3)은 2kHz, 아래 레인(2·4)은 1.2kHz, 홀드 끝(4)은 작은 900Hz, B안에서 옮긴 노트는 3kHz다. 클릭 위치는 게임 기준(음원 0초 = 1마디 시작)이다.

- **채보 요약**: 분할 수, 홀드 수, 8분 그리드 비율, 교대 규칙(홀수 마디 01/02, 짝수 마디 13/14)을 벗어난 마디 수.
- **문제 목록**: 심각도별로 출력한다. 심각도에 따른 종료 코드는 아래와 같다.

## 채보 파일 규칙 (도구가 지키는 것)

도구는 에디터 저장 형식(`EditorChartConverter.ToChartText`)과 똑같이 쓴다.

- 헤더 6줄 + 빈 줄.
- `#마디:채널레인:시퀀스;` 형식. 마디 오름차순, 레인 1→4. 방향을 정한 그룹은 두 레인 모두 쓴다.
- 마디당 시퀀스 길이는 하나(128 이하). RTL 줄은 화면 순서로 쓴다.
- CRLF, BOM 없는 UTF-8.
- `Assets/Charts`의 실제 채보 14개는 읽고 다시 쓰면 바이트까지 같다(테스트로 확인).

**주의**: ChartEditor는 채보를 메모리에 들고 있다가 S로 저장할 때 파일을 덮어쓴다. 도구가 파일을 바꾼 뒤에는 에디터에서 **다시 불러온 다음** 편집한다.

| `keep_normal_bars` | 하드에서도 일부러 노멀과 같게 둔 마디 |
| `listen_bars` | 들어 보고 판단할 마디 |
| `levels` | 생성 채보 헤더 `#LEVEL` (예: `{Easy: 3}`). 게임은 MusicSO 레벨을 쓴다 |
| `bpm`, `artist` | 신규 곡: MusicSO 가 없을 때 쓰는 정수 BPM, 헤더 `#ARTIST` |
| `gimmick_level` | 하드 기믹 범위 (기본 3): 1 노트 넘기기, 2 + 메인 라인 뒤집기·통째, 3 + 두 그룹 동시치기 |
| `rtl_suspect` | 노멀 짝수 마디(RTL 줄) 방향이 의심될 때 하드 리포트에서 그 마디 기믹에 '방향 확인' 표시 (5번) |
| `downbeat_ok`, `region` | 신규 곡: align 메트로놈으로 첫 박을 확인했는지, 채보 마지막 마디 `{last_bar: N}` |
| `sections` | 검토된 구간 맵과 1·2절 복사 규칙 (`copy_of`, `transform: same/mirror` = 짝수 간격, `cross` = 홀수 간격, `drop`). 이지·노멀·하드에 똑같이 적용 |
